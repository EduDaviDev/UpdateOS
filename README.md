# UpdateOS

### Meu sistema operacional BR🇧🇷

Versão atual: **1.0**

## Como compilar:<br>
1. Vá em releases:
<img width="849" height="471" alt="Go to releases" src="https://github.com/user-attachments/assets/28d3941d-e7a1-47ad-b761-831fc06e1445" /><br>
2. Baixe o `UpdateOS.zip`
<img width="1216" height="279" alt="Download UpdateOS.zip" src="https://github.com/user-attachments/assets/a6ddc71b-bf85-4fb2-bb71-ea82c889fa67" /><br>
3. Abra o terminal Ubuntu ou CMD <br>
4. use `cd <pasta_que_vc_extraiu>` e pressione enter<br>
5. No windows digite ´wsl --cd %cd%´ e pressione enter (se estiver no Ubuntu pule esse passo)<br>
6. digite `make run` e pressione enter
7. Pronto! o UpdateOS irá abrir!
